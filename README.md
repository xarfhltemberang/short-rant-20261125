# Angry Judge — The Short Rant Contest

Entry for `u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046`
("Angry Judge — The Short Rant Contest", deadline 2026-11-25T19:05:00Z).

## What it is

A tiny Python program (stdlib only) that writes one short, funny rant
about a single everyday annoyance — the colleague who hits reply-all
with "Thanks!" — to `/output/entry.txt`. The rant escalates from mild
irritation to full fury and lands its punch on what the original email
was actually about: a broken kettle.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing exactly the rant text,
UTF-8, 1–400 characters, with no trailing newline.
